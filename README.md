# 远望书友 · YuanWangBookFriend.koplugin

> KOReader 的 AI 辅助阅读插件，内置阅读伙伴「**小望**」：选中即问、多轮深聊，
> 并且**只基于你已经读到的内容回答**——防剧透是它的核心，不是附加功能。

当前接入 DeepSeek。已在越狱 Kindle（KPW4 / KPW6，KOReader 2026.07+）上验证通过；
安卓尚未适配。

---

## 能做什么

| 功能 | 说明 |
|---|---|
| **AI 解释** | 选中一段文字，解释其中难懂的词句、典故、人物关系 |
| **AI 摘要** | 概括当前段落或章节 |
| **轻问** | 提一个小问题，异步回答，不打断阅读流 |
| **深聊** | 多轮连续对话，可随时查看完整对话记录 |
| **你可能想问** | 不知道问什么时，给几条针对当前段落的问题（本地生成，零开销） |
| **让小望来问** | 由 AI 针对当前段落出题（会真实调用一次 API，按钮上写明了） |
| **回复风格** | 专业严谨 / 亲和友善 / 直言不讳 / 天马行空 / 高效务实 / 毒舌吐槽 / 启发引导 |
| **账户余额** | 查询 DeepSeek 账户剩余额度 |

## 防剧透是怎么做的

普通 AI 问答会把上下文整段丢给模型，于是「后面发生了什么」这种剧透防不住。
本插件的做法是**在插件侧物理截断**，而不是指望模型自觉：

1. 读取当前阅读进度（章节 / 页）；
2. 把「未读章节」的标题作为标记，在**发送前**从上下文里剪掉属于未读部分的正文；
3. 同时在 system 与 user 两侧声明当前进度，禁止引用未读内容；
4. 模型返回后，再对回答做一次本地的剧透预警替换。

管道单点在 `ywbf/deepseek.lua` 的 `DeepSeek:chat()`——所有 AI 调用都必须过这道闸。

**合集书**（一本 epub 含多部独立作品，如《十本书读懂阿加莎》）按**作品**隔离：
你当前在读哪一部，其他所有部（不论排在你前面还是后面）都视为未读。

**已知限制**：无目录的 PDF / 排版书缺少边界信号，只能按百分比估算，
属于弱防护（设置页里有明示）。紧贴选中句之后的一小段未读原文仍可能进入请求。

## 安装

1. 下载本仓库（或 Release 里的 zip）；
2. 把 `YuanWangBookFriend.koplugin` 整个目录拷贝到设备的 `koreader/plugins/` 下；
3. 重启 KOReader，主菜单 → 工具 → **远望书友**。

卸载：删掉该目录即可，插件不会往 KOReader 的全局设置里写任何东西。

## 配置 API Key

插件只支持 DeepSeek。两种方式：

- **手动粘贴**：远望书友 →「API Key 配置」；
- **从文件导入**（推荐，墨水屏手输 32 位密钥太痛苦）：
  用 USB 连电脑，把写着 Key 的文本文件放到插件 `data/` 目录，命名为 `api_key.txt`，
  然后在插件里点「从文件导入 API Key」，导入后明文文件会被自动删除。

Key 会**加密保存在插件目录内**，不以明文落盘。

## 零污染

- 所有数据（配置、缓存、对话历史、加密后的 Key）只落在插件自己的 `data/` 目录；
- 不修改 KOReader 的任何全局设置；
- 出站请求走域名白名单，且只允许 HTTPS。

## 目录结构

```
YuanWangBookFriend.koplugin/
├─ main.lua            插件入口（KOReader 加载它）
├─ _meta.lua
├─ ywbf/               纯逻辑层：不依赖 KOReader UI，可脱离设备单测
│  ├─ config.lua       设置持久化与用量统计
│  ├─ crypto.lua       AES-256-ECB（Key 加密存储）
│  ├─ httpclient.lua   HTTPS + 域名白名单
│  ├─ deepseek.lua     chat / 余额查询（防剧透管道单点在此）
│  ├─ spoiler.lua      防剧透：章节 / 合集双粒度
│  ├─ suggest.lua      建议问题的生成与 AI 输出解析
│  ├─ prompts.lua      提示词模板与回复风格
│  ├─ context.lua cache.lua store.lua queue.lua util.lua tokens.lua
└─ ui/                 UI 层：菜单、输入框、结果展示、建议选择
   ├─ settings.lua chatdialog.lua toastcard.lua asker.lua suggestpicker.lua
```

分层约定：`ywbf/` 不碰 UI（可单测），`ui/` 才碰 UI。

## 隐私提醒

选中的文本与上下文会发送给 DeepSeek 以换取回答。敏感内容请自行判断；
插件不会把这些数据发往除 DeepSeek 之外的任何地方（出站域名是白名单写死的）。
